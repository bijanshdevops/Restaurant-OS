# Operational ADRs — Restaurants OS

> Operational ADRs record decisions about tooling, infrastructure, environment configuration, and process.

---

## How to Create an Operational ADR

1. Copy [`templates/ADR_TEMPLATE.md`](../../templates/ADR_TEMPLATE.md)
2. Name the file: `ADR-NNNN-short-title.md`
3. Place in this directory (`adr/operational/`)
4. Submit a PR for Architecture Board review
