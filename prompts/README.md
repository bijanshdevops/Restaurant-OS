# Prompts — Restaurants OS

> This directory contains AI-assisted prompts for common architecture and documentation tasks.

---

## Purpose

These prompts are designed to assist the Architecture team in generating consistent, quality-controlled documentation, ADRs, and architecture review outputs using AI assistance.

## Prompt Categories

| Category | Description |
|---|---|
| `adr/` | Prompts for generating ADR content |
| `rfc/` | Prompts for generating RFC content |
| `domain/` | Prompts for domain discovery and modelling |
| `review/` | Prompts for architecture review facilitation |
| `docs/` | Prompts for generating standard documentation |

---

## Usage

Each prompt file contains:
1. The task description
2. Required context to provide
3. The prompt template
4. Expected output format

---

## Governance

- Prompts are reviewed by the Architecture Board quarterly
- AI-generated output must be reviewed by a human architect before being committed
- AI-generated ADRs and RFCs must go through the full decision process regardless of source
