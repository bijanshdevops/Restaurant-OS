## How to Use RFCs

1. Use [`templates/RFC_TEMPLATE.md`](../templates/RFC_TEMPLATE.md) to draft a new RFC
2. Place in the appropriate category directory
3. Open a PR to start the comment period (minimum 5 business days)
4. Architecture Board closes the RFC and creates ADRs for accepted proposals
